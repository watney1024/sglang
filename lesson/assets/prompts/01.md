插入位置：1.4 代码主线，启动链说明之后
画面意图：三种用法不是三个产品，最后都汇到同一个运行时。

```
STYLE: Flat vector technical diagram for an engineering textbook, light background #FAFAFA,
uniform 2px strokes, rounded rectangles, orthogonal connectors, no gradients,
no drop shadows, no 3D, no skeuomorphism, no human figures, no decorative patterns,
generous whitespace, sans-serif labels, crisp high-contrast lines, 16:9, 2x resolution.

Top: three rounded boxes in a horizontal row, evenly spaced, labeled "CLI" (blue border),
"PYTHON ENGINE" (blue border), "OPENAI API" (blue border).

From all three boxes, draw blue arrows converging down into one wide rounded container
in the middle labeled "SRT RUNTIME" with a thick blue border.

Inside the SRT container, draw three small stacked boxes labeled "API SERVER",
"SCHEDULER", "DETOKENIZER", in a vertical column.

Below the SRT container, one wide purple rectangle labeled "GPU", connected by a short
purple arrow from the SCHEDULER box.

Add a thin gray dashed arrow from "PYTHON ENGINE" directly to the "SCHEDULER" box,
passing to the right of the API SERVER box, to indicate it skips HTTP. Label it
"IN-PROCESS".
```
