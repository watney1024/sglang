插入位置：3.1 全景，进程表之后
画面意图：让读者一眼看到"三进程 + 三条通道 + GPU 在哪一侧"。

```
STYLE: Flat vector technical diagram for an engineering textbook, light background #FAFAFA,
uniform 2px strokes, rounded rectangles, orthogonal connectors, no gradients,
no drop shadows, no 3D, no skeuomorphism, no human figures, no decorative patterns,
generous whitespace, sans-serif labels, crisp high-contrast lines, 16:9, 2x resolution.

Horizontal four-column system diagram.

Far left: one small plain rectangle labeled "CLIENT".

Center-left: a tall rounded container labeled "API SERVER" at its top edge. Inside,
two stacked boxes with equal width: upper box "HTTP", lower box "TOKENIZER MGR".

Center-right: a tall rounded container labeled "SCHEDULER" at its top edge. Inside,
three stacked boxes: "SCHEDULER LOOP", "TP WORKER", "MODEL RUNNER". Below this
container, outside it, one wide purple rectangle labeled "GPU", connected to
"MODEL RUNNER" by a short purple arrow pointing down.

Far right: a medium rounded container labeled "DETOKENIZER", vertically aligned with
the middle of the SCHEDULER container.

Arrows, in drawing order:
1. Blue arrow from CLIENT to the left edge of the API SERVER container.
2. Blue arrow from "TOKENIZER MGR" rightward to "SCHEDULER LOOP", labeled "1".
3. Green arrow from "MODEL RUNNER" rightward to "DETOKENIZER", labeled "2".
4. Green arrow from "DETOKENIZER" back to "TOKENIZER MGR", routed above both tall
   containers as one clean orthogonal line, labeled "3".

Keep every label uppercase, at most two words. Leave empty space inside containers
around the inner boxes. Do not draw any extra arrows.
```

## fig-02-overlap-vs-normal.png

插入位置：3.4 调度循环，两段代码之后
画面意图：overlap 的本质是"结果处理延后一拍"，图上要能直接看出 GPU 没有空档。

```
STYLE: Flat vector technical diagram for an engineering textbook, light background #FAFAFA,
uniform 2px strokes, rounded rectangles, orthogonal connectors, no gradients,
no drop shadows, no 3D, no skeuomorphism, no human figures, no decorative patterns,
generous whitespace, sans-serif labels, crisp high-contrast lines, 16:9, 2x resolution.

Two stacked timing panels of identical width, sharing one left-to-right time axis drawn
as a thin gray arrow labeled "TIME" below the bottom panel.

TOP PANEL, titled "NORMAL" in the upper-left. Two horizontal lanes labeled at the left
edge: "GPU" for the top lane and "CPU" for the bottom lane, separated by a thin dashed
line.
On the GPU lane: three purple rectangles in a row, each labeled "FWD", with clear empty
white gaps between them.
On the CPU lane: three blue rectangles labeled "PROC", each positioned inside a gap of
the GPU lane, so the two lanes never occupy the same horizontal interval.
Inside one gap, add a small red double-headed horizontal arrow labeled "IDLE".

BOTTOM PANEL, titled "OVERLAP". Same two lanes. On the GPU lane: three purple "FWD"
rectangles placed back to back with no gap. On the CPU lane: three blue "PROC"
rectangles, each shifted right by exactly one slot relative to the GPU blocks, so
PROC n runs underneath FWD n+1.

Between the two panels, slightly right of center, draw one small orange rounded box
labeled "QUEUE" with a thin arrow in from the GPU lane and a thin arrow out to the CPU
lane, to show the one-step delay.

Use identical block sizes in both panels so the only visible difference is the gaps.
```

标签清单：`NORMAL` `OVERLAP` `GPU` `CPU` `FWD` `PROC` `QUEUE` `IDLE` `TIME`
